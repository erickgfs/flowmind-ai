Antes de começar

  • Aula 5 (Node.js e TypeScript).
  • HTML e DOM: a página é uma árvore de tags (<button>, <input>) que o JavaScript pode ler e mudar.
  • Evento: algo que acontece na página: clique, tecla, envio de formulário.

O problema e a ideia

O problema

"Mexa aqui, mexa ali"

  • Criar tarefa em JavaScript puro: achar a coluna, montar o cartão, atualizar o contador, esconder "Nenhuma tarefa".
  • Mover tarefa: desfazer tudo numa coluna e refazer na outra.
  • Esqueceu um passo? A tela mostra uma coisa e os dados dizem outra.

No React você escreve "cada coluna mostra um cartão por tarefa daquele status". Mudou o dado, o React atualiza a tela.

Analogia

A planta e o mestre de obras

  • Componente = planta reaproveitável (o cartão).
  • Props = as medidas de cada uso ("Estudar Next.js", prioridade alta).
  • Estado = a situação atual da obra (quais tarefas existem).
  • React = mestre de obras: compara e refaz só a parede que mudou.

Onde falha: reformar um prédio é caro e raro. No React, renderizar é barato e frequente; caro é mexer no DOM, e é isso que ele economiza.

Glossário

Componente
Função que recebe props e devolve um pedaço de tela.
JSX / TSX
Sintaxe parecida com HTML dentro do código: <h1>{titulo}</h1>.
Props
Os argumentos de um componente, passados como atributos.
Estado
Dado que muda e faz o componente desenhar de novo.
Renderizar
Rodar o componente para calcular como a tela deve ficar.
Hook
Função do React que começa com use.
useEffect
Sincroniza com o mundo de fora (API, localStorage, dialog) depois de renderizar.
useRef
Guarda uma referência (ex.: um elemento) sem renderizar de novo.
key
Identificador único de cada item de uma lista.
Controlado
Input cujo valor vem do estado e muda via onChange.
Suspense
Mostra um fallback enquanto a parte de dentro não pode aparecer.

Experimente: um contador

  1. Suba API e front e faça login

    cd apps/web && npm run dev   # http://localhost:3001

  2. Crie src/components/contador.tsx

    "use client";
import { useState } from "react";
export function Contador() {
  const [cliques, setCliques] = useState(0);
  return <button onClick={() => setCliques((c) => c + 1)}>
    Cliquei {cliques} {cliques === 1 ? "vez" : "vezes"}
  </button>;
}

  3. Use em task-board.tsx, depois do <h1>

    Esperado: cada clique muda o número sem recarregar a página.

  4. Coloque dois <Contador />

    Esperado: cada um tem o próprio estado.

  5. Troque por cliques++

    Esperado: erro (cliques é const). Só o set… avisa o React.

  6. Desfaça

    Remova o uso e o import e apague contador.tsx; confira com git status.

Teste seu entendimento

1. Componente, props, estado e React na analogia?

Planta, medidas de cada uso, situação da obra, mestre de obras.

2. Por que tasks.push(nova) não atualiza a tela?

Não chama o set… nem cria referência nova; o React não percebe.

3. Para que serve a key?

Identificar cada item entre renderizações, mesmo se a ordem mudar.

4. Quando usar useEffect?

Para sincronizar com algo de fora do React, não para cálculos.

5. O que a limpeza do efeito do quadro faz?

Marca ignore = true para uma resposta atrasada não alterar um quadro que saiu da tela.
