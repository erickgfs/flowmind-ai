Antes de começar

  • Aula 12 (React): as classes vão no className.
  • CSS: regras com seletor e propriedades: .botao { padding: 8px; }.
  • Variável CSS: --accent: #5b5bd6; e depois color: var(--accent);.

O problema e a ideia

O problema

CSS que só cresce

  • Nomes como .task-card__title--done, em arquivos que ninguém ousa limpar.
  • 13px aqui, 15px ali: o visual fica inconsistente.

O Tailwind oferece classes de uma coisa só (p-3, gap-2) numa escala fixa, e gera no CSS final só as que você usou.

Analogia

LEGO × massinha

  • CSS tradicional = massinha: cada peça moldada do zero.
  • Tailwind = LEGO: peças padrão que se encaixam.
  • Design tokens = a paleta oficial da caixa, com versão clara e escura.

Onde falha: no LEGO não dá para criar peça nova; no Tailwind dá (h-[37px] ou tokens próprios).

Glossário

Classe utilitária
Classe que faz uma coisa só: p-3, flex.
Design token
Decisão de design com nome: uma cor, um raio.
@theme inline
Cria classes que leem uma variável CSS (e respeitam o tema).
prefers-color-scheme
Diz se o sistema está em claro ou escuro.
Variante
Prefixo condicional: hover:, md:, focus:.
Responsivo
Layout que se adapta à largura da tela.
Escala
Cada passo vale 4px: p-1=4px, h-18=72px.

Experimente

  1. Troque o destaque num lugar só

    Em globals.css, no :root, use --accent: #0f9d76;.

    Esperado: botão, foco e logo ficam verdes sem tocar em nenhum componente.

  2. Veja o escuro

    F12 → Rendering → prefers-color-scheme: dark.

    Esperado: o destaque volta a índigo: você só mudou o valor claro.

  3. Classe montada com variável

    className={`… text-priority-${priority.toLowerCase()}`}

    Esperado: só "Média" fica amarela. text-priority-medium está escrita no ícone "Fazendo"; as outras nunca aparecem escritas, então não existem no CSS.

  4. Desfaça

    git checkout -- src/app/globals.css src/components/board/task-icons.tsx

Teste seu entendimento

1. Por que não há classes dark: no projeto?

Os componentes usam tokens que leem variáveis CSS; a variável muda com o tema.

2. O que o @theme inline faz?

Cria classes (bg-surface…) que leem var(--surface) em vez de um valor fixo.

3. Por que `bg-priority-${p}` falha?

O build procura classes escritas por inteiro no código; essa nunca aparece escrita.

4. O que significa md:flex-col?

Coluna só a partir de 768px; no celular vale a classe sem prefixo.

5. Onde trocar a cor de destaque do produto?

Em --accent (e --accent-hover) no globals.css, nos dois temas.
